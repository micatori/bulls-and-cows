# Bulls and Cows

Игра «Быки и коровы»: компьютер загадывает число из уникальных цифр в выбранной
системе счисления (bin/oct/dec/hex, длина 2–6), игрок угадывает по числу быков
(цифра на месте) и коров (цифра есть, но не на месте).

Вся игровая логика — чистые функции без DOM и без классов: генерация с инъекцией
источника случайности, сравнение попыток через функции высшего порядка,
каррированный валидатор цифр, рекурсивный мемоизированный подсчёт секретов,
иммутабельные переходы состояния.

## Запуск

npm install
npm run build # tsc → dist/ (ES-модули для браузера)
npx http-server -c-1 . # ES-модули не работают с file://

## Скрипты

| скрипт                        | назначение                                                   |
| ----------------------------- | ------------------------------------------------------------ |
| npm test                      | Vitest, окружение node, логика ядра тестируется без браузера |
| npm run lint / lint:fix       | ESLint (flat config) + typescript-eslint                     |
| npm run format / format:check | Prettier                                                     |
| npm run typecheck             | tsc --noEmit по исходникам и тестам                          |
| npm run build                 | компиляция в dist для index.html                             |

## Хуки git

- pre-commit — только lint-staged (ESLint + Prettier по изменённым файлам),
  чтобы коммит с заведомо падающими тестами (красный шаг TDD) был возможен;
- pre-push — npm test, красные тесты запушить нельзя.
